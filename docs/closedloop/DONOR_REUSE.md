# Donor Reuse Map

IX-StellaratorForge was used as a design donor for assurance concepts, not as a wholesale physics transplant.

## Adapted concepts

- exact D-T reaction source bookkeeping
- explicit Bosch-Hale authority boundary
- source-term vs transport distinction for neutronics
- conditional plant closure with unknown terms remaining unknown
- evidence canonicalization / hashing philosophy
- claim boundaries and authority labels
- convergence and sensitivity campaigns
- constrained design search philosophy

## Deliberately not imported

- ISS04 confinement scaling
- rotational transform / iota machinery
- omnigenity metrics
- stellarator field-period topology
- helical coil architecture
- stellarator-specific blanket or coil geometry

Those would be physically inappropriate in this tokamak fork.
